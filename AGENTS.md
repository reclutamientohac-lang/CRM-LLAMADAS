# Instrucciones del proyecto

Lee GEMINI.md antes de modificar el CRM. Preserva módulos, contratos de los contextos, permisos y configuración de esta versión. Cambia solo lo necesario para la solicitud.

Ejecuta npm run build antes de entregar: incluye integridad estructural, TypeScript, pruebas funcionales y pruebas del pipeline. No omitas los controles para resolver errores. Las pruebas estructurales detectan módulos desconectados, operaciones retiradas y archivos faltantes; no sustituyen una revisión del visor ni verifican datos reales o disponibilidad de Firebase.

No regeneres ni reduzcas el contrato de integridad automáticamente. Para refactorizaciones justificadas conserva el comportamiento y añade o adapta pruebas que lo demuestren. No sustituyas componentes por pantallas de relleno.

No intercambies configuración, correo administrador, Firestore ni Calendar con otro repositorio. Los ajustes de código no autorizan modificar registros operativos.
